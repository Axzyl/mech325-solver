Iteration Procedure (Combined Loading Only)

⚠️ ITERATIVE PROCEDURE REQUIRED
Follow Steps 6-14 on pages 4-5 of PDF:
  1. Calculate Fa/C0 ratio
  2. Look up e from Table 11-1
  3. Check if Fa/(VFr) > e
  4. If true: Interpolate Y₂ from Table 11-1, set X₂ = 0.56
  5. If false: Use X₁, Y₁ from Table 11-1
  6. Recalculate Fe with new Xi, Yi
  7. Calculate new C10 = (new Fe / old Fe) × old C10
  8. Select bearing with new C10
  9. If same bearing: CONVERGED! Done!
  10. If different bearing: Repeat from step 1

General Equations Reference

Angular Speed from Power

$$n_D = \frac{63025 H}{T}$$

Radial Load

$$F_R = \sqrt{F_x^2 + F_y^2}$$

Individual Bearing Reliability

$$R_i = \sqrt[n]{R_{tot}}$$

Design Life in Revolutions

$$L_D = 60 \times \mathcal{L}_D \times n_D$$
Where 𝓛D is in kilohours, nD in rpm, result in revolutions

Multiple of Rating Life

$$x_D = \frac{L_D}{L_{10}}$$
Where L10 is in 10⁶ revolutions

Design Load (Radial Only)

$$F_D = a_f F_R$$

Catalog Rating (Radial Only)

$$C_{10} = a_f F_D \left[\frac{x_D}{x_0 + (\theta - x_0)[\ln(1/R_i)]^{1/b}}\right]^{1/a}$$

Equivalent Radial Load (Combined)

$$F_e = X_i V F_r + Y_i F_a$$

Design Load (Combined)

$$F_D = a_f F_e$$
