Step 9: Check Convergence and Iterate

ITERATION INSTRUCTIONS:
1. After selecting bearings in Step 8, note the K factors (Knew,A, Knew,B)
2. Update KA and KB in Step 2 with these new values
3. Recalculate - this will update FiA, FiB, FeA, FeB, and C10 values

6. If different bearings: Repeat steps 2-5

General Equations Reference

Radial Load Calculation

$$F_r = \sqrt{R_x^2 + R_y^2}$$

Induced Load

$$F_i = \frac{0.47 F_r}{K}$$

Equivalent Load (Piecewise)

$$\text{Case 1: If } F_{iA} \leq (F_{iB} + F_{ae})$$ $$F_{eA} = 0.4 F_{rA} + K_A(F_{iB} + F_{ae})$$ $$F_{eB} = F_{rB}$$
$$\text{Case 2: If } F_{iA} > (F_{iB} + F_{ae})$$ $$F_{eB} = 0.4 F_{rB} + K_B(F_{iA} - F_{ae})$$ $$F_{eA} = F_{rA}$$

Life Calculations

$$L_D = 60 \times \mathcal{L}_D \times n_D$$
$$x_D = \frac{L_D}{L_{10}}$$

Reliability

$$R_i = \sqrt[n]{R_{tot}}$$

Load Rating

$$C_{10} = a_f F_e \left[\frac{x_D}{x_0 + (\theta - x_0)[\ln(1/R_i)]^{1/b}}\right]^{3/10}$$
Where a = 10/3 for tapered roller bearings
