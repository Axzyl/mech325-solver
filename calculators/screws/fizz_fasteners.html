General Equations Reference

Bolt Length (Configuration a)

$$l = t_1 + t_2$$
$$L = l + H$$

Bolt Length (Configuration b)

$$l = h + \frac{t_2}{2} \text{ if } t_2 < d, \text{ else } h + \frac{d}{2}$$
$$L = h + 1.5d$$

Threaded Length

$$L_T = 2d + \text{constant}$$
For inches: If L ≤ 6", then LT = 2d + 0.25. Otherwise LT = 2d + 0.5
For mm: If L ≤ 125mm and d ≤ 48mm, then LT = 2d + 6. If L ≤ 200mm, then LT = 2d + 12. Otherwise LT = 2d + 25
$$l_d = L - L_T$$
$$l_t = l - l_d$$

Bolt Stiffness

$$A_d = \frac{\pi d^2}{4}$$
$$k_b = \frac{A_d A_t E_b}{A_d l_t + A_t l_d}$$

Safety Factors

$$C = \frac{k_b}{k_b + k_m}$$
$$n_L = \frac{S_p A_t - F_i}{CP}$$
$$\sigma_b = \frac{CP + F_i}{A_t}$$
$$n_p = \frac{S_p}{\sigma_b}$$
$$n_0 = \frac{F_i}{P(1-C)}$$
$$T = K F_i d$$

Fatigue (Goodman)

$$\sigma_i = \frac{F_i}{A_t}$$
$$\sigma_a = \frac{CP}{2A_t} \text{ (repeated)}$$
$$\sigma_m = \sigma_a + \sigma_i \text{ (repeated)}$$
$$n_f = \frac{S_e (S_{ut} - \sigma_i)}{\sigma_a (S_{ut} + S_e)}$$
