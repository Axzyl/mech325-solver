General Equations for Compression Springs

Spring Geometry

$$C = \frac{D}{d} \quad OD = D + d \quad ID = D - d$$

Stress Correction Factors

$$K_s = \frac{2C + 1}{2C}$$ $$K_W = \frac{4C - 1}{4C - 4} + \frac{0.615}{C}$$ $$K_B = \frac{4C + 2}{4C - 3}$$ $$K_C = \frac{K_B}{K_s}$$

Shear Stress

$$\tau = K_B \frac{8FD}{\pi d^3}$$ $$\tau_a = \frac{\tau_{max} - \tau_{min}}{2}$$ $$\tau_m = \frac{\tau_{max} + \tau_{min}}{2}$$

Material Properties

$$S_{sy} = 0.577S_y$$ $$S_{su} = 0.67S_{ut}$$

Spring Rate and Deflection

$$k = \frac{d^4G}{8D^3N_a}$$ $$y = \frac{F}{k}$$

Lengths

$$L_s = d \cdot N_t \quad \text{(for most end types)}$$ $$L_{loaded} = L_0 - y$$

Safety Factors

$$F_s = (1 + \xi)F_{max}$$ $$n_s = \frac{S_{sy}}{\tau_s}$$

Fatigue (Goodman Criterion)

$$S_{se} = \frac{S_{sa}}{1 - \frac{S_{sm}}{S_{su}}}$$ $$n_f = \frac{S_{se}}{\tau_a + \frac{S_{se}}{S_{su}}\tau_m}$$

Fatigue (Gerber Criterion)

$$n_{f,Gerber} = \frac{1}{2}\left(\frac{S_{su}}{\tau_m}\right)^2 \cdot \frac{\tau_a}{S_{se}} \left[-1 + \sqrt{1 + \left(\frac{2\tau_m S_{se}}{S_{su}\tau_a}\right)^2}\right]$$

Static Design - Spring Index Calculation

$$\alpha = \frac{S_{sy}}{n_s}$$ $$\beta = \frac{8(1+\xi)F_{max}}{\pi d^2}$$ $$C = \frac{2\alpha - \beta}{4\beta} + \sqrt{\left(\frac{2\alpha - \beta}{4\beta}\right)^2 - \frac{3\alpha}{4\beta}}$$ $$D = C \cdot d$$

Static Design - Constraint-Based Mean Diameter

$$\text{Over-a-rod: } D = d_{rod} + d + allowance$$ $$\text{In-a-hole: } D = d_{hole} - d - allowance$$

Critical Buckling Length

$$(L_0)_{cr} = \frac{2.63D}{\alpha_{end}}$$

where αend depends on end conditions (0.5 for fixed-fixed, 0.707 for fixed-hinged)

Figure of Merit

$$fom = -(\text{rel. cost}) \cdot \frac{\gamma \pi^2 d^2 N_t D}{4}$$

Critical Frequency

$$W = \frac{\pi^2 d^2 D N_t \gamma}{4}$$ $$f_n = \frac{1}{2}\sqrt{\frac{k \cdot g}{W}}$$

where g = 386.4 in/s² (gravitational constant). Operating frequency should be ≤ 0.8fn.
