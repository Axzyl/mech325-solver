General Equations for Compression Springs

Spring Geometry

$$C = \frac{D}{d} \quad OD = D + d \quad ID = D - d$$

Stress Correction Factors

$$K_s = \frac{2C + 1}{2C}$$ $$K_W = \frac{4C - 1}{4C - 4} + \frac{0.615}{C}$$ $$K_B = \frac{4C + 2}{4C - 3}$$ $$K_C = \frac{K_B}{K_s}$$

Shear Stress

$$\tau = K_B \frac{8FD}{\pi d^3}$$ $$\tau_a = \frac{\tau_{max} - \tau_{min}}{2}$$ $$\tau_m = \frac{\tau_{max} + \tau_{min}}{2}$$

Material Properties

$$S_{sy} = 0.577S_y$$ $$S_{su} = 0.67S_{ut}$$

Spring Rate and Deflection

$$k = \frac{d^4G}{8D^3N_a}$$ $$y = \frac{F}{k}$$

Lengths

$$L_s = d \cdot N_t \quad \text{(for most end types)}$$ $$L_{loaded} = L_0 - y$$

Safety Factors

$$F_s = (1 + \xi)F_{max}$$ $$n_s = \frac{S_{sy}}{\tau_s}$$

Fatigue (Goodman Criterion)

$$S_{se} = \frac{S_{sa}}{1 - \frac{S_{sm}}{S_{su}}}$$ $$n_f = \frac{S_{se}}{\tau_a + \frac{S_{se}}{S_{su}}\tau_m}$$
